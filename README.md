# 핏로그 (FitLog)

운동 기록 + 식단·칼로리 + 체중을 한 번에 기록하는 개인용 웹앱(PWA)이에요.
설치 없이 브라우저에서 열고, 폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요. 한 번 열면 오프라인에서도 동작해요.

## 주요 기능
- **오늘**: 오늘 식단 요약(칼로리·단백질) + 운동 기록. 세트별 중량·횟수 입력, 지난번과 비교(볼륨·최고 중량·예상 1RM ▲▼), **더블 프로그레션** 다음 목표(같은 무게로 모든 세트가 범위 위쪽에 닿을 때만 최소 단위 증량), 지난번과 같아도 좋은 결과로 안내, 정체 알림(4번 이상 + 21일 이상 제자리일 때만, 잠·식사 → 2주 유지 → 가벼운 디로드), **상위 몇 %**(같은 성별·체중·나이 이용자 기준 추정)
- **식단**: 아침/점심/저녁/간식별 음식 기록. 공공 식품성분 DB 음식 302개(100g당 값 + 출처 + 생것/익힌 것 구분)와 브랜드 공식 메뉴(버거킹·맥도날드·롯데리아·스타벅스)를 합쳐 검색할 수 있어요. 브랜드 메뉴는 단품 1개·세트 1개·감자튀김 R 1개·Tall 1잔처럼 직관적인 분량으로 넣었어요. '도시락김 1봉(4.5g)', '황태채 한 줌(약 10g)' 같은 분량 버튼이나 정확한 g으로 입력하고, 칼로리·단백질·탄수·지방을 바로 보여줘요. 마지막에 먹은 양을 기억해요. 직접 입력할 때는 비슷한 음식 값 채우기, 분량 감 잡기, 영양성분표 읽는 법을 안내해요. 체중 기록도 있어요
- **히스토리**: 날짜별/종목별 기록, 종목별 그래프, 체중 추세(7일 평균), 종목별 내 수준(상위 %) 요약, 종목 화면의 수준 막대·이번 달 기대치
- **운동법**: 189개 운동 모두 **자세 그림**(앱이 직접 그린 SVG, 오프라인 동작: 시작↔끝 움직임 애니메이션, 시작·끝 자세, 움직이는 길, 번호 핵심 포인트, 호흡, 타깃 근육 앞/뒤 그림, 플라이·아웃타이/인타이는 위에서 본 그림). (가슴·등·어깨·하체·둔근·팔·복근·유산소)의 타깃 근육, 동작 순서, 흔한 실수, 권장 세트/횟수, 증량 단위
  - 핵스쿼트·펜듈럼·브이스쿼트, 아웃타이/인타이, 머신 벤치·인클라인 머신, 디클라인, 펙덱(팩트플라이), 리버스 펙덱·리어델트 레이즈, 해머(플레이트) 머신, 케이블, 스미스, 유산소 머신 등
  - 부위·장비 필터, 별명 검색(띄어쓰기 무시: "핵 스쿼트", "팩트플라이", "아웃타이", "숙더프레스")
  - 어시스티드 풀업/딥스는 보조 kg(낮을수록 어려움), 유산소는 분 + 거리(km)로 기록
- **루틴**: 추천 템플릿 3가지(주 3회 전신 · 주 4회 상체/하체 · 주 5회 상/하체 + 밀기/당기기/하체). 날마다 종목·세트×반복 범위·휴식, 부위별 주간 세트 요약(주동근 1 · 보조근 0.5, 주 10~20세트 구간 표시). 종목 바꾸기(같은 동작·같은 부위, 내 헬스장 기구 먼저)·빼기·세트 −/＋. 오늘 탭의 **오늘 루틴 시작**은 그날 종목을 지난번 무게와 더블 프로그레션 목표 무게로 채워요. `fitlog.v1`의 `routine` 필드에 저장(예전 데이터는 그대로 열려요)
- **짐80 · 파나타 기구**: 88개(짐80 41 · 파나타 47). 운동 선택·운동법에 브랜드 필터(전체/짐80/파나타/일반), 설정 → **내 헬스장 기구**를 고르면 목록 앞쪽에 나오고 루틴도 그 기구로 맞춰요
- **설정**: 키·체중·나이·성별·활동량·목표로 하루 칼로리(Mifflin-St Jeor)·단백질 목표 계산, JSON 백업/복원, 코치용 텍스트 복사, 코치 데이터 붙여넣기, **근거 화면**(공식·논문 DOI·데이터 출처)

## 데이터
모든 기록은 **이 기기 브라우저(localStorage)** 에만 저장돼요. 서버로 전송되지 않아요.
브라우저 데이터를 지우거나 기기를 바꾸면 사라질 수 있으니 **설정 → 백업 파일 저장**을 가끔 해 주세요.

## 상위 % 데이터
`standards.js`는 `tools/build_standards.py`가 만들어요. 원자료는 `tools/strengthlevel_snapshot.json`(Strength Level 표준표 스냅샷, 데이터 기준일 2026-03-10, 성별 × 체중표 × 나이표)과 `tools/exrx_untrained.json`(ExRx 성인 비훈련자 1RM, 18~39세)이에요.
- 순위는 **헬스장/앱 이용자 기록 기준 추정**이에요. 일반인 전체 기준이면 순위가 더 높게 나와요.
- ExRx 표는 규준(순위)이 아니라서 "비훈련자 참고값"으로만 보여 줘요.
- 표가 없는 종목은 표시하지 않아요 (65개 종목 지원). 종목 ↔ 표 연결은 `build_standards.py`의 `MAP`에 있어요.
- 함수 코드는 `tools/standards_fn.js`에 있어요. 고친 뒤 `python3 tools/build_standards.py`로 다시 만들어요.

다시 만들기: 원자료를 `$FOODDATA`(기본 `/workspace/fooddata`)에 `rda_kfct10.csv`, `mfds_dish.csv`, `mfds_processed.csv`, `usda_sr/`로 두고 `python3 tools/build_foods.py`를 실행해요. 원자료는 용량이 커서 저장소에 넣지 않았어요.
"한 줌", "1봉" 같은 분량의 g은 제품 표시중량, 식약처 1인분 중량, 일반 계량 기준이에요. "약"이 붙은 분량은 어림값이에요.

예전 버전에서 기록한 식단은 그때 저장한 칼로리·영양소 그대로 유지돼요. 예전 방식(1회 제공량 기준)으로 만든 '내 음식'도 그대로 쓸 수 있어요.

## 코치 데이터 붙여넣기 형식
```json
{
  "date": "2026-11-03",
  "meals": [
    {"meal": "점심", "name": "제육덮밥", "amount": "1그릇", "kcal": 800, "protein": 32, "carbs": 100, "fat": 28}
  ],
  "workouts": [
    {"exercise": "벤치프레스", "sets": [[62.5, 8], [62.5, 8]]}
  ],
  "weight": 75.2
}
```
- `meal`: 아침/점심/저녁/간식 (breakfast/lunch/dinner/snack, 야식도 인식)
- `kcal` 필수, `protein`·`carbs`·`fat`은 g (먹은 양 전체 기준)
- `sets`: `[중량kg, 횟수]` 목록 (맨몸은 중량 0, 플랭크는 `[0, 초]`), `{"weight":40,"reps":10}` 형식도 가능
- 여러 날짜는 배열 `[{...}, {...}]`로. 앞뒤 설명 문장이나 ```json 코드블록이 섞여 있어도 괜찮아요.
