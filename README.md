# 핏로그 (FitLog)

운동 기록 + 식단·칼로리 + 체중을 한 번에 기록하는 개인용 웹앱(PWA)이에요.
설치 없이 브라우저에서 열고, 폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요. 한 번 열면 오프라인에서도 동작해요.

## 주요 기능
- **오늘**: 오늘 식단 요약(칼로리·단백질) + 운동 기록. 세트별 중량·횟수 입력, 지난번과 비교(볼륨·최고 중량·예상 1RM ▲▼), 정체기 알림, 다음 목표 추천
- **식단**: 아침/점심/저녁/간식별 음식 기록. 공공 식품성분 DB에서 가져온 음식 302개(100g당 값 + 출처 + 생것/익힌 것 구분). '도시락김 1봉(4.5g)', '황태채 한 줌(약 10g)' 같은 분량 버튼이나 정확한 g으로 입력하고, 칼로리·단백질·탄수·지방을 바로 보여줘요. 마지막에 먹은 양을 기억해요. 직접 입력할 때는 비슷한 음식 값 채우기, 분량 감 잡기, 영양성분표 읽는 법을 안내해요. 체중 기록도 있어요
- **히스토리**: 날짜별/종목별 기록, 종목별 그래프, 체중 추세(7일 평균)
- **운동법**: 189개 운동(가슴·등·어깨·하체·둔근·팔·복근·유산소)의 타깃 근육, 동작 순서, 흔한 실수, 권장 세트/횟수, 증량 단위
  - 핵스쿼트·펜듈럼·브이스쿼트, 아웃타이/인타이, 머신 벤치·인클라인 머신, 디클라인, 펙덱(팩트플라이), 리버스 펙덱·리어델트 레이즈, 해머(플레이트) 머신, 케이블, 스미스, 유산소 머신 등
  - 부위·장비 필터, 별명 검색(띄어쓰기 무시: "핵 스쿼트", "팩트플라이", "아웃타이", "숙더프레스")
  - 어시스티드 풀업/딥스는 보조 kg(낮을수록 어려움), 유산소는 분 + 거리(km)로 기록
- **설정**: 키·체중·나이·성별·활동량·목표로 하루 칼로리(Mifflin-St Jeor)·단백질 목표 계산, JSON 백업/복원, 코치용 텍스트 복사, 코치 데이터 붙여넣기, **근거 화면**(공식·논문 DOI·데이터 출처)

## 데이터
모든 기록은 **이 기기 브라우저(localStorage)** 에만 저장돼요. 서버로 전송되지 않아요.
브라우저 데이터를 지우거나 기기를 바꾸면 사라질 수 있으니 **설정 → 백업 파일 저장**을 가끔 해 주세요.

## 음식 데이터 출처
`foods.js`는 `tools/build_foods.py`가 원자료에서 자동 생성해요 (음식 목록과 분량은 `tools/food_spec.py`). 값은 모두 100g(음료·국물은 100ml)당이에요.

| 표시 | 원자료 | 받는 곳 |
|---|---|---|
| 농진청 | 농촌진흥청 국가표준식품성분표 제10개정판 (원출처가 수산과학원·USDA·일본성분표인 항목은 앱에 함께 표기) | data.go.kr 15137343 |
| 식약처 | 식약처 통합식품영양성분정보(음식) — 외식·가정식, 1인분 중량. 섞인 음식이라 **추정**으로 표시 | data.go.kr 15100070 |
| 식약처 제품 | 식약처 통합식품영양성분정보(가공식품) — 같은 종류 시판 제품 여러 개의 100g당 **중앙값** | data.go.kr 15100066 |
| USDA | USDA FoodData Central SR Legacy (2018-04) | fdc.nal.usda.gov |

다시 만들기: 원자료를 `$FOODDATA`(기본 `/workspace/fooddata`)에 `rda_kfct10.csv`, `mfds_dish.csv`, `mfds_processed.csv`, `usda_sr/`로 두고 `python3 tools/build_foods.py`를 실행해요. 원자료는 용량이 커서 저장소에 넣지 않았어요.
"한 줌", "1봉" 같은 분량의 g은 제품 표시중량, 식약처 1인분 중량, 일반 계량 기준이에요. "약"이 붙은 분량은 어림값이에요.

예전 버전에서 기록한 식단은 그때 저장한 칼로리·영양소 그대로 유지돼요. 예전 방식(1회 제공량 기준)으로 만든 '내 음식'도 그대로 쓸 수 있어요.

## 코치 데이터 붙여넣기 형식
```json
{
  "date": "2026-11-03",
  "meals": [
    {"meal": "점심", "name": "제육덮밥", "amount": "1그릇", "kcal": 800, "protein": 32, "carbs": 100, "fat": 28}
  ],
  "workouts": [
    {"exercise": "벤치프레스", "sets": [[62.5, 8], [62.5, 8]]}
  ],
  "weight": 75.2
}
```
- `meal`: 아침/점심/저녁/간식 (breakfast/lunch/dinner/snack, 야식도 인식)
- `kcal` 필수, `protein`·`carbs`·`fat`은 g (먹은 양 전체 기준)
- `sets`: `[중량kg, 횟수]` 목록 (맨몸은 중량 0, 플랭크는 `[0, 초]`), `{"weight":40,"reps":10}` 형식도 가능
- 여러 날짜는 배열 `[{...}, {...}]`로. 앞뒤 설명 문장이나 ```json 코드블록이 섞여 있어도 괜찮아요.

## GitHub Pages로 올리기
1. 이 폴더를 GitHub 저장소로 push
2. 저장소 **Settings → Pages → Branch: main / (root)** 선택
3. `https://<아이디>.github.io/<저장소이름>/` 에서 열기 → 폰에서 홈 화면에 추가

빌드 과정 없음 · 외부 라이브러리 없음 · 모든 경로가 상대경로라 하위 경로에서도 동작해요.

## 주의
음식 값은 공공 DB의 평균값이라 실제 음식과 다를 수 있어요. 포장지 영양성분표가 있으면 그 값이 가장 정확해요. 운동 중 통증이 있으면 즉시 멈추고 전문가와 상담하세요.
